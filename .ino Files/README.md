## Anchor
Anchor holds all the code for UWB and triangulation control. We currently have code to triangulate the position of a UWB tag and visualize it in Python.
## Robot
Robot holds all the code for controlling and moving the robot. We currently have code to move the wheels up and down and drive the robot around and pure pursuit to a given point.
## Anchor Robot
Holds RTOS code for combining triangulation and pursuit
